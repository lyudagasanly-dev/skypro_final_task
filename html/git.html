Git

  • git init — инициализация локального репозитория.
  • git add . — индексация всех измененных файлов.
  • git commit -m "сообщение" — фиксация изменений.
  • git push — отправка изменений в удаленный репозиторий.
  • git status — проверить состояние репозитория (какие файлы изменены).
  • git pull — забрать (скачать) обновления из удаленного репозитория.
  • git clone [ссылка] — скопировать чужой репозиторий к себе на компьютер.
